# Pelican on a bicycle: weights under IK

![Harmonic weights through one pedal cycle](preview.gif)

A procedurally drawn, layered pelican pedals a bicycle. Both legs are single painted meshes (thigh, shin and foot) driven by two-bone IK to pedals on a rotating crank. The neck and head share one three-bone mesh. Everything else is rigid. The case exercises the [skin-weights](../../skills/2d/skin-weights/SKILL.md) pipeline end to end and checks it with the [spine-skeletal](../../skills/2d/spine-skeletal/SKILL.md) audit.

```sh
python examples/pelican-bicycle/run.py --out /tmp/pelican-review
```

Exit 0 means both expected outcomes were reproduced:

| Weights | Lint | Fold audit | Visible fold pixels |
|---|---|---|---|
| Harmonic, declared per-bone cores | PASS | PASS | 0 |
| Rigid nearest-bone control | FAIL | FAIL | 126 far leg, 183 near leg |

Both ankles stay on their pedals within 1e-13 world units over 121 samples at 60 Hz. The near knee swings 36° to 113°. Its minimum triangle area ratio is 0.04: no fold, but a near-collapse to review by eye. The runner writes the GIFs and contact sheets beside the reports for that review.

## What it shows

- **Seams are now caught before deformation.** The first configuration used one handle radius for every leg bone. The fold audit found a fold at the ankle, between foot and shin rigid zones that touched. The seam lint added for this case rejects that configuration without running any motion.
- **Transition width is the design knob.** With a 22% core inset the knee folded one visible pixel at full flexion. 30% passes.
- **Export is verified, not assumed.** `export_rigc.py --verify-rigc` compiled this rig with rig-c 2.79.0 and posed it with rig-c's own core. Every vertex of all 11 layers matched within 2e-5 world units. IK is baked into keys in that export. The official Spine parser was not run.

## Files

- `make_art.py`: deterministic generator for `source/` (layers, rig, motion). Run by `run.py`.
- `run.py`: mesh, harmonic and control weights, lint, IK trace, audit, surface measure and renders.
