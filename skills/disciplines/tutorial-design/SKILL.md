# Tutorial design

Ask: diegetic | overlay-hint | separate-yard.
Three beats for each new verb: see it → use it safe → use it under pressure (`level-design`).
A hint names the verb already taught. It does not solve the room.
Skipable after the first clear. Never freeze the combat clock to print a paragraph.

Accept: a player who skipped text can still execute the verb in the next room.
