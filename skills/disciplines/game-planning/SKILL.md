# Game planning

Write column picks into the slice doc so later skills do not guess.
The slice must demonstrate feel columns, not a menu.
Fix first: input latency, camera, locomotion. If those are missing, do not grow the map.

## Slice accept (play, not features)

A slice is done when a player can:

1. Understand the goal
2. Finish one meaningful fight
3. Take a reward
4. Name the next hook

Grow the map only after `gameplay-validation` / real-input passes that chain. Teleport and cleared-room tests do not count.
