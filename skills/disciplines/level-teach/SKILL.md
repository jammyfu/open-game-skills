# Level teach

Ask the column (one verb per beat).

| Column | Space does |
|---|---|
| show | player sees the verb used or the obstacle that needs it |
| safe-try | must use the verb; fail is cheap (no run-wipe) |
| test | same verb, now with a cost |
| remix | old verb + one new constraint |

Do not skip safe-try. A text box is not safe-try.

## Beat order

```
show → safe-try → test → (later) remix
```

Introduce one verb. Reinforce it once in the same session. Mix it with an old verb only after both have a test.
The first death to that verb must point at the tell the room already showed (attack-tell / platform-jump).

## Iron rules

- Safe-try has an exit that does not require coyote, frame-perfect parry, or a wiki.
- Prompts name the job already bound (input-design). They do not author a second control.
- Skip-cutscene does not skip safe-try (cutscene-handoff + tutorial-design).
- Ability-gate: teach on the safe side of the door, test on the far side.
- Do not drop a new verb in the same room as a new elite kit.
- First-session-value: the first taught verb must finish one meaningful beat.

## Accept

A stranger can name the new verb after the safe-try room. They can fail the test once and retry without a load-screen essay. A designer can point at show / safe-try / test on a map, not only in a script.
