# Matchmaking

Ask first: casual, ranked, or private?

Columns: casual-pool | ranked-mmr | private-code | local-only.

Rules: netcode column stays `netcode-feel`. Ranked may not silently change hitstop. Long queue is a setup issue (`gameplay-validation`), not a reason to buff the loser. Party members use one ticket (`party-follow` does not apply online unless you said so).

Accept: a private code always finds that room. Casual does not hide a hidden MMR that bans new players from a first match.
