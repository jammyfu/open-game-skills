# Deck build

Ask first: fixed-deck, draft, or roguelike-add (`roguelike-run`)?

Rules: a card is a published verb or number. Cards that change hitstop are a feel rewrite — refuse. Shuffle fairness is visible; pity if any is `pity-table`. Mana / energy is a stamina cousin (`stamina-clock`), not a second combat clock.

Accept: the player can name why a card is in the deck. Required first fight is possible with the starter deck.
