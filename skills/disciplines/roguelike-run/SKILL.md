# Roguelike run

Ask the column.

| Column | Death | Between runs |
|---|---|
| true-reset | all gear gone | knowledge only |
| light-meta | keep a currency / slot | no combat clock change |
| daily-seed | shared seed | comparable clears |
| endless-heat | modifiers stack | same verbs |

## Loop

```
pick / roll seed → enter node → fight or skip → shop or rest → next node → die or clear
```

A node is an encounter-design room with a published exit. Do not generate a novel verb mid-run.

## Iron rules

- Seed is logged. Two players with the same seed see the same map column (layout may still be authored rooms).
- Meta unlocks new *options*, not silent +damage that hides a bad tell.
- Shops use shop-price / currency-dual. They do not sell cancel windows.
- Death writes the run summary. It does not quietly write story-slot bosses as cleared (save-integrity).
- Heat / ascension modifiers are listed on the run start card.

## Accept

A first run can finish a node with the starting kit. A death is readable (what killed you, what you had). Rerolling the seed changes the map, not the feel column.
