# Grapple and swing

Ask the column:

| Column | After latch |
|---|---|
| no-grapple | none |
| latch-pull | pull to point or pull object |
| pendulum | swing then release jump |

## Rules

1. Fire, latch, slack, release are moves on the graph.
2. Aim uses look or a published snap to tagged points. Untagged latch is a column, not a default.
3. Camera-anti-clip still runs. The rope is not a clip ignore.
4. Jump-leniency may help the release jump. It may not teleport through a wall.
5. A bot that misses every latch is automation until a human tape lands it.

## Accept

Player can name a legal hook point in the room. Release lands on nav or fall-rules apply.
