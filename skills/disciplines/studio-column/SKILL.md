# Studio column

A studio word is a column pick, not a franchise pack.

| They say | Columns you may pick |
|---|---|
| Nintendo / Zelda-like | world-map region-unlock+pins · camera-anti-clip orbit-third · ability-gate · level-teach · durability consume or unbreakable |
| Capcom / fighter-like | fighting-design grounded-footsies · action-feel short-special · kb-mouse-map fighter-plane |
| Capcom / character-action | action-feel long-cancel · combo-design · lock-on-target |
| Konami / castlevania-like | ability-gate tool-gate · level-teach · platform-jump |
| Blizzard / ARPG-like | equipment-progression affix · inventory-economy · difficulty chosen-tier |
| indie | honest-fixed difficulty · few buttons · one combat clock |

Rules: still max 3 disciplines. Do not load a missing `skills/studios/*` path. Do not copy a finished stage. Wear and combat stay one column each.

Accept: after the name you can say which three files you opened. There is no fourth secret Nintendo skill.
