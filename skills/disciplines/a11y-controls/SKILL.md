# A11y controls

Ask which flags are on: remap, toggle-sprint, hold-to-tap, mono-audio, color-shape, text-scale, reduced-flash, mouse-keys.
Flags may not change cancel windows or hitboxes.
Colorblind: shape + text (`hud-feedback`). Fighter motion inputs get a simple-input alias (`input-design`).

Accept: a one-handed or no-color pass can finish the slice.
