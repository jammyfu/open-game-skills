# Climb and vault

Ask the column:

| Column | What the body may do |
|---|---|
| mantle | short hop onto a ledge |
| full-climb | stamina or meter on a surface |
| no-climb | jump only |

## Rules

1. Attach and detach are moves with start frames. Instant roof-stand is a bug.
2. If stamina-clock exists, climb drain is a published cost.
3. Camera-anti-clip still runs against the wall.
4. Jump and interact are not the same key on a 3D climber.
5. Falling off uses fall-rules.

## Accept

A new player can name how to get onto the ledge.
