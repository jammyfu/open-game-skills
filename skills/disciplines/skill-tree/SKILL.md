# Skill tree

Ask first: linear, branch, or web?

Rules: a node is a verb or a number, published. Numbers that change hitstop are a feel rewrite — refuse. New verbs teach on the safe side (`ability-gate`, `tutorial-design`). Refunds are a column. Debug unlocks stay in lab (`save-integrity`).

Accept: the player can point at the next node they want. Turning a node off does not shrink someone else's hurtbox.
