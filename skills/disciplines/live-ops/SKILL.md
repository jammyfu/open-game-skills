# Live ops

Ask first: cosmetic event, convenience pack, or mode remix?

Rules: remix may change encounter mix (`encounter-design`), not hitstop. Packs use `iap-offers`. Event end returns the slice to the published column. Do not raise enemy HP in the dark to sell a potion.

Accept: after the event, yesterday's build still boots. A missed event does not brick a required verb.
