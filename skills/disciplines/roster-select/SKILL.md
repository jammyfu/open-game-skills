# Roster select

Ask: even-roster | unlock-grid | random-only.
Each fighter publishes the same columns: action-feel, kb-mouse-map, hit-hurt boxes.
Color / costume is juice. It may not change frame data.
Last-pick and random are flags. Blind select is for versus only.

Accept: two players can read who they picked before the round clock starts.
