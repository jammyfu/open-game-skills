# Quest graph

Ask: one-hook | hub-board | rumor-web.
Pins belong to the player (`world-map`). The system may mark the *active* hook only.
A quest is a graph of conditions, not a GPS polyline. Optional branches do not block the main hook.
Rewards name the column they feed (gear A drop, bag slot, verb unlock).

Accept: the pause log lists one next action the player already understands.
