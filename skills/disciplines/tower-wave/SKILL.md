# Tower wave

Ask: lane-path | budget-wave | endless-ramp.
A wave is a published count and interval. Spawn uses `rng-seed`. Enemies still have kits (`enemy-kit-balance`) and perception (`enemy-perception`). Selling a cancel window as a tower upgrade is a monetization bug.

Accept: two runs with one seed spawn the same first wave. A dead lane is a path bug, not extra HP.
