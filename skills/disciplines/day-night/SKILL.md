# Day night

Ask: cosmetic | spawn-table | stealth-light | none.
If stealth-info is on, night changes cones and noise, not hitboxes.
Sleep is a save-checkpoint column, not a required time skip.
Do not level-sync the world because the clock moved.

Accept: the player can use time as a tool or ignore it and still finish the hook.
