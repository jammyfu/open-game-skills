# Studio-inspired column selection

A studio name is a reference, not a game specification or a folder to invent. Inspect the requested genre and existing project before selecting a mode. These are proposed design directions, not claims about proprietary implementations.

| Cue | Candidate choices |
|---|---|
| Open-field exploration | [world-map](../world-map/SKILL.md): open-air; [camera-anti-clip](../camera-anti-clip/SKILL.md): orbit-third |
| Grounded versus fighter | [fighting-design](../fighting-design/SKILL.md): grounded-footsies; [action-feel](../action-feel/SKILL.md): short-special; [kb-mouse-map](../kb-mouse-map/SKILL.md): fighter-plane |
| Character action | [action-feel](../action-feel/SKILL.md): long-cancel; [combo-design](../combo-design/SKILL.md): action-string |
| Ability-gated rooms | [ability-gate](../ability-gate/SKILL.md): tool-gate; [world-map](../world-map/SKILL.md): metroidvania |
| Stealth | [stealth-info](../stealth-info/SKILL.md): cone-alert |
| Affix-based equipment | [equipment-progression](../equipment-progression/SKILL.md): C Affix; select difficulty separately |
| Indie or generic | No automatic preset. Preserve the project's choices and resolve the actual verb or symptom. |

## Handoff

Record selected skill names, their own column values, evidence and any unresolved choice. A studio name alone does not authorize changing the engine, clock, inputs, economy or assets. Ask at most one consequential question; do not make the user name files.

This picker occupies a specialized slot while loaded. Hand off its choices and unload it before a three-discipline implementation phase. The execution limit remains three specialized skills plus one necessary engine per phase; secondary work is deferred, not discarded.

## Accept

The selected paths exist inside the installed pack, every mode belongs to its selected skill, and no duplicate preset owner is loaded. The singular studio-column entry delegates here. Do not copy commercial maps, characters, prompts, assets or frame tables.
