# Studio columns

A studio name is **not** a skill folder. Load this file, then pick columns
from disciplines that already exist. See [docs/PRESETS.md](../../../docs/PRESETS.md).

| They say | Pick (examples) | Do not |
|---|---|---|
| Nintendo / Zelda / Mario | world-map region-unlock + pins, ability-gate, level-teach show→safe-try→test, camera-anti-clip orbit-third, input-design few-buttons | copy a map or a button prompt set |
| Capcom / Street Fighter / DMC | fighting-design grounded-footsies **or** action-feel long-cancel — one combat clock, attack-tell, hitstun-recover | mix SF and DMC clocks on one actor |
| Konami | stealth-info cone-alert, or rhythm-judge if they said music | paste a franchise setlist |
| Blizzard / Diablo-like | equipment-progression affix, loot as verbs, not silent +frames | copy an itemization table |
| indie | honest-fixed difficulty, few verbs, unbreakable wear unless they asked shatter | assume a studio clock |

## Iron rules

- Max three disciplines + this picker. Then work.
- Studio flavor is camera, teach order, and which column. It is not a hidden frame chart.
- If the named house has no matching column, ASK one question. Do not load a missing path.
