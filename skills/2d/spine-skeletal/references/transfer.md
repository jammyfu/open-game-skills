# Repository integration and field evidence

This package extends the existing `2d/spine-skeletal` owner. Keep its entrypoint, relative references and executable helpers together when installing the skill pack. Project-specific texture generation, engine bundling and runtime exporters remain adapters, rather than hardcoded dependencies of the portable audit.

The [runnable weighted-skinning case](https://github.com/jammyfu/open-game-skills/tree/main/examples/weighted-skinning) and [live comparison](https://jammyfu.github.io/open-game-skills/weighted-skinning/) show actual evaluated good/rejected limb traces. The complete pack also contains `hd-sprite-sequence` for independent image identity and sequence checks; do not make the rig audit claim that responsibility.

The source field trial used a continuous mesh with fixed bone lengths. A narrow 200 px envelope passed file/weight checks while 2,529 visible source pixels lay in inverted triangles. A revised 480 px envelope passed zero visible bad UV pixels over the same sweep. Those widths belong to that source plate and must not become universal defaults.

The reusable lesson is to inspect evaluated geometry plus actual source alpha, review anatomy independently and retain rejected evidence. Synthetic fixtures exercise malformed input, contact/loop drift and invisible canvas folds; the checked-in runtime case reproduces the actual opposite PASS/FAIL outcomes. Case artwork/provenance stays in the repository example, outside the installable Skill. No full-character, native gameplay, model or human-study acceptance is inferred.
