# Skeleton and face control for whole-figure redraws

This is an authoring workflow. It does not add a character runtime or prove semantic image identity. Use the measurement harness for independently observed output, and keep unaccepted art out of publication.

1. **Pin the complete model.** Use an approved coherent full-body drawing and a clean facial close-up from that same model. Pin their bytes. Record physical/logical density, torso/shoulder and limb-chain lengths, crown-to-chin and skull dimensions, jaw/cheek width, brow/eye/nose/mouth/chin points, outfit and view. A broken assembled rig is not an anatomy reference. A face that changes view or scale is not repaired by resizing the whole figure.
2. **Author a separate control guide.** Draw an actor origin, floor/contact marks, common camera/density and fixed grid for every sample. Draw fixed anatomical bone lengths plus a same-size head ellipse and same relative facial layout. Declare projected far-side lengths and genuine occlusions **before** generation. Use original pose references to place/rotate the joints and set root/contact trajectories. A crouch or lean may move the crown/chin/waist; common anatomical dimensions do not mean forcing every pose point onto one horizontal line. Do not stretch a bone to hit a desired wrist or contact coordinate.
3. **Request a continuous drawing.** Supply the complete model, clean face and control/pose guides together. Ask for one connected human figure per pose: natural shoulder-to-elbow-to-wrist anatomy, coherent armholes/straps, pelvis/knee/calf direction and planted shoes. Guides must not appear in final images. Avoid cutout plugs, detached limbs, anatomical kinks, repeated idle substitutes and per-cell fitting. Lock the same camera, view, head/face size, bone lengths and anatomical ratios across the strip. Label a reference-only image tool as **reference-guided**; only claim enforced skeletal/face conditioning when the actual model/API controls are configured and recorded. A prompt or guide image cannot by itself promise a hard lock.
4. **Review the first pixels promptly.** Inspect a common-scale sheet, same-window face/shoulder/elbow close-ups, normal/slow playback and source pose comparisons. Check continuous anatomy and intended guard/contact changes before broad runtime testing. Record failing frame IDs and actual numerical head/face/torso/limb differences. A better-looking strip may still fail facial identity, camera scale or pose fidelity. Do not treat tool tests or a successful import as visual acceptance.
5. **Handle contaminated alpha conservatively.** If transparent references/output carry colored exterior RGB/fringes, generate the whole drawing on an opaque neutral matte with clean dark contours. Preserve the raw result. A mechanical mask may remove only boundary-connected background using a documented sampled color/tolerance, while keeping retained artwork RGBA unchanged. Inspect light/dark composites, holes, thin limbs and edge pixels. Do not globally erase a color, erode the body, repaint through grid lines or silently normalize individual frames. If registration requires a density conversion, one predeclared uniform transform must apply to every pose; it cannot fix changed face/body ratios.
6. **Measure independently and gate.** The authored guide contains expected targets, never observations. Re-read the generated PNG and independently mark actual visible landmarks with reviewer, hashes and uncertainty. Run the pinned identity/anatomy/contact/temporal checks at the declared density. A model that ignores the guide stays failed/blocked; record the actual deviations instead of copying control coordinates into observations, relaxing tolerances or claiming a face/bone lock succeeded. Publish only complete required coverage with source, geometry, visual and engine evidence.

Useful evidence includes the raw model/face/pose inputs, hashed control guide and projected-length declarations, exact generation prompt/provider mode, untouched generated sheet, mechanical mask/transform records, same-scale comparisons, independent actual-image measurements and per-frame rejection reasons. Keep target guides, output measurements and review judgments separate.
