# Pay-wall methods (case notes)

A public app-monetization skill pack (HammingDev/haiming-app-monetization, MIT) is a *method source* for walls and SKUs. It is not a game design pack and not a conversion promise.

Keep in cases, not iron laws:

- Read live code paths, not old comments.
- Separate code facts, store facts, and guesses.
- Do not write lift percents without a window and a denominator.
- A debug member flag is a lab slot.

Game columns stay in `iap-offers` and `first-session-value`.
